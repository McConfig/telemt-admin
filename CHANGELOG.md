# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [1.10.4] — 2026-11-27

### Исправлено

- non-Bearer `Authorization` больше не блокирует cookie-сессию;
- лимиты 50 сервисов и 20 токенов проверяются атомарно;
- токен проверяется по индексу сервиса, осиротевший токен отклоняется;
- неизвестный scope трактуется как viewer, а не admin;
- создание сервиса атомарно: сбой не оставляет занятое имя.

## [1.10.3] — 2026-11-27

### Изменено

- выбор колонок через «три точки» теперь есть во всех таблицах данных:
  клиенты, аудит, пользователи UI, сервисы, сессии, устройства и история
  IP; набор сохраняется для пользователя UI отдельно для каждой таблицы.

## [1.10.2] — 2026-11-27

### Добавлено

- настройка видимости колонок таблицы клиентов через «три точки»; выбор
  сохраняется для пользователя UI.

### Изменено

- убрана дублирующая колонка «Открыть»: переход в карточку остаётся по
  имени клиента;
- по умолчанию скрыты второстепенные колонки, чтобы таблица помещалась
  без горизонтальной прокрутки.

## [1.10.1] — 2026-11-27

### Исправлено

- таблица клиентов снова прокручивается горизонтально и не обрезает колонки;
- футер прижат к низу экрана;
- управление темами перенесено в профиль пользователя UI;
- кнопка сворачивания сайдбара находится вверху под логотипом.

## [1.10.0] — 2026-11-27

### Добавлено

- боковая навигация `AsideHeader` со сворачиванием и сохранением
  состояния;
- пять тем Gravity UI: системная, светлая, тёмная и две контрастные;
- все формы, даты, кнопки и preview-таблицы переведены на компоненты
  Gravity UI.

## [1.9.0] — 2026-11-26

### Добавлено

- сервисные аккаунты и API-токены с правами `read / write / admin`,
  сроком жизни или без него, отзывом, отключением сервиса и аудитом;
- аутентификация по `Authorization: Bearer` с единым principal и
  запретом управления токенами по токену;
- страница «Сервисные аккаунты» с выпуском, одноразовым показом и
  отзывом токенов.

## [1.8.0] — 2026-11-26

### Добавлено

- импорт клиентов из CSV: проверка без записи, шаблон, предпросмотр по
  строкам, отчёт «создано / пропущено / ошибка», пропуск существующих
  клиентов и аудит импорта.

## [1.7.0] — 2026-11-26

### Добавлено

- массовый сброс квот выбранным клиентам или всем с отчётом
  «сброшено / отказано / неизвестно / не отправлено»;
- автосброс квот по глобальному расписанию и переопределение на клиента:
  «как у всех», «не сбрасывать» или свой интервал и время;
- блокировка одновременного ручного и планового сброса, обновление точки
  отсчёта после ручного сброса и аудит плановых операций;
- вкладка «Квоты» на странице настроек.

### Исправлено

- смена периода графиков больше не перезагружает карточку клиента и не
  перетирает несохранённые поля формы.

### Изменено

- пороги CI закреплены: 85% для API, 85% строк, инструкций и функций UI,
  70% ветвей.

## [1.6.0] — 2026-11-26

### Добавлено

  бэкапы, 2FA и предупреждения;

## [1.5.1] — 2026-11-26

### Исправлено

## [1.5.0] — 2026-11-26

  бэкапов; приложение пишет конфиг для хостового скрипта и читает статус.

## [1.4.1] — 2026-11-25

### Добавлено

## [1.4.0] — 2026-11-25

### Добавлено

## [1.3.1] — 2026-11-25

### Изменено

## [1.3.0] — 2026-11-25

### Добавлено

- страница «Настройки»: реестр глобальных настроек, приоритет env и
  `settings:global`, версия и аудит `settings.update`, planned и readonly
  пункты, домашняя страна, TTL сессий, режим ссылок, интервал и retention;
- шаблоны лимитов: CRUD, шаблон по умолчанию, применение к новому и
  существующему клиенту;
- панели бэкапов и системы, ручной `BGSAVE`, история изменений;


## [1.2.0] — 2026-11-25

### Добавлено

- пороги риска на клиента: `PUT /api/users/{name}/risk`, ключ
  `risk:user:*`, блок «Пороги риска» в карточке, аудит `user.risk`;
- отчёт по риску: `GET /api/users/{name}/risk-report`, `risk.csv`,
  вкладка «Риск», причины, дни, время первого и последнего появления
  адреса за день, доверие IP и стране;
- ключи `iphist:dayfirst:*` и `iphist:daylast:*` для времени внутри дня;
- демо-стенд `deploy/demo`: фейковый Control API telemt, Valkey, seed
  истории за 8 дней, генератор демо-GeoIP и скриншоты Playwright;
- workflow `sign-releases.yml` для подписи уже опубликованных релизов:
  cosign, SBOM, `.sig`, `.pem` и SPDX-аттестация;
- ручной запуск Scorecard через `workflow_dispatch`;
- Dependabot alerts и security updates включены в настройках репозитория;
- подписаны cosign релизы v1.1.4-v1.1.7: у всех пяти последних релизов
  есть SBOM, `.sig` и `.pem`; Signed-Releases в Scorecard вырос до 8.

### Изменено

- защита `main` переведена с classic branch protection на repository
  ruleset: те же проверки `test`, `security`, `e2e`, линейная история,
  запрет force-push и удаления;
- исправлены документы: убраны утверждения о Gitleaks и Semgrep, которых
  нет в CI, добавлены secret scanning и push protection GitHub.

## [0.9.0] — 2026-11-24
