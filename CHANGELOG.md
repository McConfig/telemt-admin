# История изменений

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

## [2.1.2] — 2026-11-27

### Добавлено

- у каждой карточки настроек появилась иконка скачивания YAML-фрагмента
  только этих настроек;
- на главном заголовке «Настройки» — выгрузка всех системных настроек и
  шаблонов лимитов в один YAML;
- на главном заголовке «Прокси telemt» — выгрузка полного `config.toml`;
- у групп прокси сохранена выгрузка TOML-фрагмента.

### Безопасность

- секреты в YAML системных настроек не выгружаются.

## [2.1.1] — 2026-11-27

### Исправлено

- JSON-модалка получила фиксированный размер: 1040 px по ширине и
  стабильную высоту, область ошибки не сдвигает окно;
- длинные имена параметров больше не переносятся: «?» остаётся на той
  же строке, первая колонка выравнивается по самому длинному имени;
- текст подсказки получил внутренние отступы и больше не липнет к краю;
- при фокусе поле становится белым, изменённая строка подсвечивается
  жёлтой рамкой.

### Изменено

- третья колонка с чекбоксом убрана: boolean-параметры теперь
  выбираются через `select` со значениями `true` и `false`;
- поиск работает и по значениям параметров, не только по ключам;
- у каждой группы прокси появилась иконка скачивания TOML-фрагмента
  именно этой группы.

## [2.1.0] — 2026-11-27

### Добавлено

- архитектура мультиязычности UI: `LocaleProvider`, `useLocale()` и
  `t()` с сохранением языка в `localStorage`;
- русский словарь описаний всех параметров прокси;
- генератор словаря из официального `CONFIG_PARAMS.ru.md` telemt и
  ручных дополнений для WEB-параметров;
- подсказки «?» на вкладке «Прокси» теперь на русском, с fallback на
  описание из схемы telemt.

### Изменено

- `fake-telemt` отдаёт английские описания, как настоящий telemt, чтобы
  демо проверяло русский словарь, а не совпадение языков.

## [2.0.3] — 2026-11-27

### Изменено

- в таблице прокси убраны повторяющиеся заголовки, заголовок один;
- верхнеуровневые группы сворачиваются и разворачиваются;
- у каждого параметра появился «?» с подсказкой из схемы telemt;
- boolean-параметры показываются только чекбоксом, без подписи
  «включено/выключено»; у остальных колонка пустая;
- поле получает белый фон при фокусе, а рамка изменённого параметра
  подсвечивается жёлтым;
- JSON-редактор увеличен, область ошибки фиксирована и не сдвигает окно;
- длинные имена параметров переносятся, а не выходят за ячейку.

## [2.0.2] — 2026-11-27

### Изменено

- вкладка «Прокси» переведена на таблицу «Параметр — Значение —
  Включено», каждая строка параметра в отдельной рамке;
- boolean-параметры показываются чекбоксом в колонке «Включено»;
- массивы и объекты редактируются в модальном JSON-окне с подсветкой
  ошибки и блокировкой применения невалидного JSON;
- добавлен поиск по путям и описаниям параметров;
- глобальная панель «Сохранить настройки» скрыта на вкладке «Прокси».

## [2.0.1] — 2026-11-27

### Исправлено

- импорт клиентов больше не отправляет `null` для лимитов, которых нет в
  файле, и не сбрасывает существующие переопределения;
- удаление отсутствующих пользователей запрещает удалять текущего
  администратора;
- пустая заметка в файле не очищает заметку существующего клиента.

## [2.0.0] — 2026-11-27

### Добавлено

- экспорт и импорт конфигурации в YAML `tgadmin.telemt/v1`: системные
  настройки, шаблоны лимитов, конфигурация прокси, пользователи UI,
  сервисные аккаунты и клиенты;
- предпросмотр импорта: diff по блокам, конфликты имён с выбором
  «оставить / переписать», список удаляемых сущностей;
- режимы «слияние» и «замена» для настроек и прокси;
- редактор прокси через Control API telemt: схема, валидация, применение
  с `If-Match`, перезагрузка и статус;
- подтверждение паролем и TOTP-кодом для экспорта и импорта секретов;
- аудит `config.export`, `config.import.*`, `proxy.update`, `proxy.reload`.

### Безопасность

- секреты не выгружаются без явного подтверждения;
- запрещено удаление или понижение текущего и последнего администратора;
- удаление отсутствующих сущностей требует отдельного подтверждения
  именем установки;
- строгий YAML без алиасов, якорей и дублей ключей, лимит 4 МиБ;
- лимиты частоты на экспорт и импорт.
