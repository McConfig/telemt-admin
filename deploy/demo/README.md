# Демо-стенд TeleMT Admin

Демонстрационное окружение для скриншотов, документации и знакомства с
интерфейсом. В нём работает настоящий `tgadmin`, но вместо telemt —
фейковый Control API с детерминированными данными. Реальный прокси, домены
и секреты не нужны.

## Что внутри

| Сервис | Назначение |
|---|---|
| `tgadmin` | настоящий образ `ghcr.io/mcconfig/telemt-admin` |
| `fake-telemt` | маленький Go-сервис, повторяющий Control API telemt |
| `valkey` | хранилище пользователей, истории, аудита и сессий |
| `seed` | разовое наполнение: пользователи UI, история за 8 дней, аудит |

Данные фейкового прокси: 8 клиентов, адреса из RFC 5737
(`192.0.2.0/24`, `198.51.100.0/24`, `203.0.113.0/24`), страны RU, NL, DE,
один отключённый клиент, один с истёкшим сроком, один у квоты. Ссылки ведут
на `demo.example.com` и не работают как прокси.

`fake-telemt` не проксирует MTProto-трафик. Он реализует только методы,
которые вызывает `tgadmin`:

- `GET /v1/capabilities`;
- `GET /v1/users`, `POST /v1/users`;
- `GET`, `PATCH`, `DELETE /v1/users/{name}`;
- `POST /v1/users/{name}/reset-quota`, `rotate-secret`, `enable`, `disable`.

## Требования

- Docker с Compose;
- свободный порт `8090` на localhost;
- для скриншотов — Node.js 24+ и Chromium для Playwright.

## Запуск

Все команды выполняются из каталога `deploy/demo`.

1. Создайте файл окружения:

   ```bash
   cd deploy/demo
   cp .env.example .env
   ```

   В `.env` можно сменить пароли Valkey и пользователей UI. Порты наружу не
   публикуются, поэтому значения по умолчанию безопасны для локальной
   машины.

2. Соберите фейковый telemt и поднимите сервисы:

   ```bash
   docker compose up -d --build
   ```

   Ожидаемый результат: три контейнера в состоянии `running` —
   `telemt-admin-demo-fake-telemt-1`, `telemt-admin-demo-valkey-1`,
   `telemt-admin-demo-tgadmin-1`.

3. Проверьте, что сервисы живы:

   ```bash
   docker compose ps
   curl -fsS http://localhost:8090/healthz
   ```

   `curl` должен вернуть `ok`. Если вернул ошибку, смотрите логи:

   ```bash
   docker compose logs --tail=50 tgadmin
   ```

4. Наполните демо-данными:

   ```bash
   docker compose --profile seed run --rm seed
   ```

   Ожидаемый вывод:

   ```text
   демо готово: 8 клиентов, пользователи demo/viewer
   вход: http://localhost:8090
   ```

   Seed идемпотентен: пароли пользователей UI перевыставляются, история
   адресов перезаписывается, аудит дополняется.

5. Откройте <http://localhost:8090> и войдите:

   | Логин | Пароль | Роль |
   |---|---|---|
   | `demo` | `demo-admin-password` | admin |
   | `viewer` | `demo-viewer-password` | viewer |

   Пароли задаются в `.env` переменными `DEMO_ADMIN_PASSWORD` и
   `DEMO_VIEWER_PASSWORD`. Если вы их изменили, используйте свои.

## Что смотреть

- **Клиенты** — 8 записей, сортировка по любому заголовку, риск, страны,
  иностранные адреса, квоты.
- **Карточка клиента** — график трафика, история адресов, новые страны,
  доверенные адреса, лимиты, перевыпуск ссылки.
- **Аудит** — входы, создание, перевыпуск, лимиты и доверенные адреса за
  последние сутки.
- **Администраторы** — список пользователей UI и их роли.
- **Аккаунт** — смена пароля, сессии, TOTP (в демо не включён).
- **Настройки** — глобальные пороги риска, домашняя страна, шаблоны
  лимитов, статус Valkey и системная панель. Planned-настройки видны, но
  неактивны.

История за 8 дней создаётся seed: у `travel-phone` новая страна появляется
4 дня назад, у `router-home` на третий день добавляется гость, у
`phone-main` доверен Netherlands. Поэтому видны графики и новые страны, а не
пустые таблицы.

## Смена версии tgadmin

По умолчанию используется `v1.6.0`. Другая версия:

```bash
TGADMIN_VERSION=v1.3.1 docker compose up -d tgadmin
```

## Скриншоты

Скриншоты генерируются Playwright из работающего стенда.

1. Установите зависимости фронтенда и Chromium:

   ```bash
   cd frontend
   npm ci
   npx playwright install chromium
   ```

2. Снимите экраны:

   ```bash
   npm run screenshots:demo
   ```

   Скрипт входит как `demo`, проходит по страницам и складывает PNG в
   `docs/screenshots/`:

   - `login.png` — вход;
   - `clients.png` — список клиентов;
   - `client.png` — карточка клиента;
   - `audit.png` — аудит;
   - `admins.png` — администраторы;
   - `account.png` — аккаунт;
   - `new-client.png` — создание клиента.

3. Другой адрес или пароль:

   ```bash
   DEMO_BASE_URL=http://127.0.0.1:8090 \
   DEMO_USER=demo \
   DEMO_PASSWORD=demo-admin-password \
   npm run screenshots:demo
   ```

## Остановка и удаление

Остановить контейнеры, сохранив данные:

```bash
cd deploy/demo
docker compose down
```

Удалить контейнеры и том Valkey:

```bash
docker compose down -v
```

Удалить собранные образы демо:

```bash
docker compose down --rmi local
```

## GeoIP

Чтобы демо показывало страны и операторов без лицензионных баз, в
`deploy/demo/geoip` лежат две маленькие mmdb-базы. Они собраны генератором:

```bash
go run -tags demo ./hack/gen-demo-geoip
```

Базы содержат только RFC 5737 и не пересекаются с реальными адресами.
Пересобирать их нужно только при изменении списка стран или операторов.

## Ограничения

- Нет MTProto-прокси: ссылки в интерфейсе демонстрационные и не подключаются.
- Нет TOTP: для демо он не включён, иначе скриншоты требовали бы код.
- Нет реального GeoIP: страны определяются по демо-базам.
- Данные не совпадают с продакшеном и не предназначены для обучения модели
  на реальном трафике.
- Стенд слушает только `127.0.0.1:8090`; не публикуйте его в интернет.

## Если что-то не работает

**Порт 8090 занят.** Остановите другой процесс или измените порт в
`docker-compose.yml` (`127.0.0.1:8090:8090`) и в `TGADMIN_BASE_URL`.

**Seed пишет `Control API: ...`.** Фейковый telemt ещё не поднялся.
Подождите несколько секунд и повторите:

```bash
docker compose ps
docker compose logs --tail=30 fake-telemt
docker compose --profile seed run --rm seed
```

**Вход не работает.** Убедитесь, что seed выполнен, а в `.env` те же пароли,
что вы вводите. Cookie в демо не `Secure`, поэтому вход работает только по
`http://localhost:8090`, не по IP-адресу.

**Пустые страны.** Проверьте, что каталог `geoip` смонтирован:

```bash
docker compose exec tgadmin ls -l /opt/geoip
```

Ожидаются `demo-city.mmdb` и `demo-asn.mmdb`.
