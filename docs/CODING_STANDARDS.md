# Стандарты кода

Стандарты обязательны для изменений в `main`. Большая часть проверяется в
CI, остальное — на код-ревью.

## Go

- `gofmt` обязателен; `go vet` и `golangci-lint` должны проходить.
- Пакеты небольшие, по назначению: `web`, `store`, `collector`, `telemt`,
  `auth`, `totp`, `geoip`, `config`.
- Ошибки оборачиваются с контекстом: `fmt.Errorf("что: %w", err)`.
- Ошибки не игнорируются; если игнорирование осознанное, ставится `_ =` и
  комментарий, либо `// #nosec` с причиной.
- Внешние HTTP-вызовы принимают `context.Context` и имеют таймаут.
- Секреты не логируются; сообщения telemt редактируются.
- Для проверки IP используется `netip`, для JSON — `encoding/json` с
  ограничением размера тела.
- Тесты: табличные, `httptest`, `miniredis`; fuzz-цели для парсеров.

## TypeScript и React

- Строгий режим TypeScript, `npm run typecheck` обязателен.
- Запрещён `any` без объяснения; типы API лежат в `src/api.ts`.
- Компоненты Gravity UI; стили — в `styles.css`, без случайных inline-
  стилей, кроме простых отступов.
- Пользовательские строки на русском; английское описание — в
  `README.en.md`.
- Тесты Vitest для логики и страниц; Playwright для сквозных сценариев.

## Имена и текст

- Go: `camelCase`, экспортируемые — `PascalCase`.
- JSON API: `camelCase`; поля, которые видит только admin, не попадают в
  ответы для viewer.
- Комментарии и документация — по-русски, кроме публичного английского
  README и кода.
- В Ansible все `- name:` — на русском.

## Git

- Один PR — одна логическая change.
- Сообщения в стиле `feat(scope): ...`, `fix(scope): ...`,
  `docs: ...`, `ci: ...`.
- В PR описывается, что изменено, как проверено и есть ли миграции.
- `main` защищён: PR, зелёные `test`, `security`, `e2e`, линейная история.

## Безопасность

- Не коммитить секреты, токены, приватные ключи, реальные IP и ссылки.
- Новые зависимости проверяются на лицензию и уязвимости.
- Пользовательский ввод валидируется на границе.
- Изменения аутентификации, TOTP, CSRF и доступа требуют отдельных тестов.

## Документация

- Публичные API и переменные окружения описаны в `README.md` и
  `docs/API.md`.
- Изменения схемы Valkey — в `docs/UPGRADE.md`.
- Пользовательские изменения — в `CHANGELOG.md`.
