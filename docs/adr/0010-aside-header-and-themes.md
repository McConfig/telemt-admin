# ADR-0010: AsideHeader и полный набор тем Gravity UI

- Статус: принято
- Дата: 2026-11-27
- Контекст: версия 1.10.0

## Проблема

Интерфейс использовал самодельный верхний topbar с мобильным бургером,
ручную тему через `data-theme` и нативные `select`, `input`, `checkbox`,
`textarea`. Поддерживались только светлая и тёмная темы, хотя uikit
предлагает четыре встроенные темы и режим `system`. Самодельные контролы
хуже работали с темами, контрастностью и клавиатурной навигацией.

## Решение

1. Перевести каркас на `AsideHeader` из `@gravity-ui/navigation`:
   боковое меню, логотип, аккаунт и выход; состояние сворачивания
   хранится в `localStorage`.
2. Сделать `Provider` uikit единственным источником темы и русской
   локали. Поддержать `system`, `light`, `dark`, `light-hc`, `dark-hc`.
3. Выбор темы вынести в `Select` сайдбара; в свёрнутом состоянии —
   отдельная кнопка с диалогом.
4. Заменить нативные формы на `TextInput`, `Select`, `Checkbox`,
   `TextArea`, `DateField`; файловый ввод — на `useFileInput`.
5. Перевести preview-таблицы на `@gravity-ui/table`, нативные кнопки — на
   `Button`.
6. Удалить CSS самодельного topbar и нативных контролов, оставить
   семантические токены `--g-*`.
7. QR и TOTP-изображения оставить на белом фоне: это требование
   сканируемости, а не темы.

## Альтернативы

1. **Оставить topbar и только добавить темы.** Меньше изменений, но
   самодельная навигация и нативные контролы продолжали бы расходиться
   с дизайн-системой.
2. **Использовать `PageLayout`.** Даёт больше контроля для сложного
   каркаса, но для одного меню и футера достаточно `AsideHeader`.
3. **Только аудит без миграции.** Отчёт не улучшает интерфейс и оставляет
   те же проблемы.
4. **Не добавлять date-components.** Пришлось бы оставить нативные
   `date`/`datetime-local`; выбран `DateField` с русской локалью.

## Последствия

- Новые зависимости: `@gravity-ui/navigation`, `@bem-react/classname`,
  `@gravity-ui/date-components`, `@gravity-ui/date-utils`.
- Все темы доступны без перезапуска и сохраняются между сессиями.
- Нативные контролы в `src` исчезают, кроме скрытого input внутри
  `useFileInput`.
- Меняются DOM-селекторы e2e; тесты переведены на роли и доступные имена.
- Сайдбар на узких экранах по умолчанию свёрнут.
