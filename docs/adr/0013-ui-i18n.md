# ADR-0013: Мультиязычность UI и русские описания прокси

- Статус: принято
- Дата: 2026-11-27
- Контекст: версия 2.1.0

## Проблема

Интерфейс tgadmin полностью русский, строки захардкожены в компонентах.
Подсказки параметров прокси приходят из `GET /v1/config/schema` telemt и
написаны на английском. Из-за этого в русском интерфейсе появлялись
английские пояснения.

## Решение

1. В фронтенде появляется слой локализации:
   - `LocaleProvider` хранит выбранный язык в `localStorage`
     (`tgadmin-locale`), по умолчанию `ru`;
   - `useLocale()` даёт `locale`, `setLocale` и `t(key, fallback)`;
   - общие строки UI будут постепенно переноситься в
     `src/i18n/messages.ts`.
2. Подсказки прокси переводятся в фронтенде:
   - `src/i18n/proxy.ru.ts` — словарь `path → русское описание`;
   - `proxyDescription(path, schemaDescription, locale)` сначала берёт
     словарь выбранного языка, затем описание из схемы telemt.
3. Русский словарь генерируется скриптом
   `hack/gen-proxy-descriptions.py`:
   - основной источник — официальный `CONFIG_PARAMS.ru.md` telemt;
   - для полей, которых там нет (в основном WEB), используется
     `hack/proxy-descriptions.ru.extra.json`.
4. Скрипт проверяет, что для всех отображаемых в UI путей есть русское
   описание, и падает со списком пропусков.
5. Переключатель языка пока не выводится: архитектура готова, но UI
   остаётся русским. Английский режим использует описания из схемы.

## Альтернативы

1. **Переводить на бэкенде и отдавать готовый текст.**
   Привязывает API к языку клиента и мешает будущему переключению в UI.
2. **Автоперевод схемы на лету.**
   Непредсказуемое качество, внешняя зависимость, лишняя задержка.
3. **Хранить описания в каждом компоненте.**
   Дублирование и невозможность переиспользовать словарь.
4. **Оставить английские подсказки.**
   Не соответствует основному языку интерфейса.

## Последствия

- При обновлении telemt и изменении схемы нужно перегенерировать словарь:
  `python3 hack/gen-proxy-descriptions.py --docs ... --schema ...`.
- Новые пути без перевода показывают английское описание из схемы.
- `LocaleProvider` уже оборачивает приложение, поэтому следующие шаги —
  перенос общих строк в `uiMessages` и добавление переключателя языка.
- Словарь хранится в репозитории и не требует сети в CI.
